VERSÃO 0.2.0 - [Data: 2025-12-11]
================================================================================

RESUMO DA VERSÃO:
- Adicionada funcionalidade de refresh de cache do Git Updater
- Implementado workflow GitHub Actions para releases automáticas
- Adicionado toggle de debug para facilitar depuração
- Corrigido erro de permissões no workflow do GitHub Actions

--------------------------------------------------------------------------------
FUNCIONALIDADES ADICIONADAS:
--------------------------------------------------------------------------------

1. REFRESH DE CACHE DO GIT UPDATER
   - Arquivo: inc/admin-refresh-cache.php
   - Descrição: Adiciona botão "Atualizar Cache" na lista de plugins do WordPress
   - Funcionalidades:
     * Botão na lista de ações do plugin (plugins.php)
     * Endpoint AJAX com verificação de permissões (manage_options)
     * Verificação de nonce para segurança
     * Limpa cache do Git Updater via Singleton
     * Executa wp_cron() após limpar cache
   
   - Arquivo: assets/js/admin-refresh-cache.js
   - Descrição: Script JavaScript para interação do botão
   - Funcionalidades:
     * Clique no botão "Atualizar Cache"
     * Feedback visual durante processamento (spinner)
     * Mantém posição de scroll após atualização
     * Exibe mensagens de sucesso/erro

2. WORKFLOW GITHUB ACTIONS
   - Arquivo: .github/workflows/release.yml
   - Descrição: Automação para criar tags e releases automaticamente
   - Funcionalidades:
     * Detecta versão automaticamente do arquivo principal
     * Cria tag no formato v{VERSÃO}
     * Cria release no GitHub automaticamente
     * Executa apenas na branch develop
     * Verifica se tag já existe antes de criar
     * Logs detalhados para debugging

3. TOGGLE DE DEBUG
   - Arquivo: packing-panel-woo-dev.php (linhas 18-29)
   - Descrição: Constante para ativar/desativar debug facilmente
   - Funcionalidades:
     * Constante PPWOO_DEBUG_MODE no topo do arquivo
     * Exibe erros PHP quando ativado
     * Integrado com método is_debug() da classe Config
     * Fácil de alterar sem modificar classes internas

--------------------------------------------------------------------------------
CORREÇÕES REALIZADAS:
--------------------------------------------------------------------------------

1. CORREÇÃO DE INDENTAÇÃO YAML
   - Arquivo: .github/workflows/release.yml
   - Problema: Indentação incorreta do bloco env: causava erro de sintaxe
   - Solução: Ajustada indentação do env: para alinhar com with:

2. CORREÇÃO DE PERMISSÕES GITHUB ACTIONS
   - Arquivo: .github/workflows/release.yml
   - Problema: Erro "Resource not accessible by integration"
   - Solução: Adicionada seção permissions: contents: write
   - Impacto: Workflow agora pode criar tags e releases

3. MELHORIAS NO WORKFLOW
   - Adicionados logs informativos no step de detecção de versão
   - Melhor tratamento de erros no script de criação de tag
   - Mensagens de release mais completas e formatadas
