FUNCIONALIDADES ADICIONADAS:
--------------------------------------------------------------------------------

1. WEBHOOK EXTERNO (CONSULTA DE PEDIDOS)
   - Arquivo: inc/admin/class-admin-connection-tab.php
   - Descrição: Nova seção na aba Conexão para configurar webhook externo
   - Funcionalidades:
     * Campo URL separado para consulta externa
     * Select método HTTP: GET ou POST
     * Toggle "Usar autenticação" (Bearer Token)
     * Campo Bearer Token (mascarado quando preenchido)
     * Descrição informando que POST envia JSON body
   - Opções salvas:
     * ppwoo_external_webhook_url
     * ppwoo_external_webhook_method (get|post)
     * ppwoo_external_webhook_auth_enabled (yes|no)
     * ppwoo_external_webhook_bearer_token

2. CLIENT DE WEBHOOK EXTERNO COM GET/POST + BEARER
   - Arquivo: inc/integrations/class-webhook-client.php
   - Descrição: Refatoração completa do client para suportar GET/POST e autenticação
   - Funcionalidades:
     * Método fetch() atualizado:
       - Lê configurações do webhook externo (não mais do webhook de eventos)
       - GET: adiciona parâmetros na URL via add_query_arg()
       - POST: envia JSON body via wp_remote_post()
       - Header Authorization: Bearer <token> quando auth habilitada
     * Logs detalhados:
       - método, url (sem token), payload (sem token), status code, tempo, preview do body
     * Parâmetros padrão: {"action":"get_orders","channel":"whatsapp"}

3. NORMALIZAÇÃO DE PAYLOAD
   - Arquivo: inc/integrations/class-webhook-client.php
   - Descrição: Normalização de pedidos externos conforme external-order-contract.txt
   - Funcionalidades:
     * Método normalize_external_order():
       - Aceita formatos: {orders: [...]} ou [...]
       - Mapeia/normaliza chaves de pedidos externos para formato esperado
       - Suporta billing.* e billing_* (campos diretos)
       - Normaliza shipping_methods, items, coupons, meta campos
       - Loga estruturas inesperadas via PPWOO_Debug::warn()
     * Validação:
       - Verifica se pedido é array
       - Valida ID obrigatório
       - Sanitiza todos os campos

4. INTEGRAÇÃO DE PEDIDOS EXTERNOS NO PAINEL
   - Arquivo: inc/core/class-orders.php, inc/core/class-utils.php, templates/painel.php
   - Descrição: Mesclagem de pedidos WooCommerce e externos no fluxo de renderização
   - Funcionalidades:
     * PPWOO_Orders atualizado:
       - get_motoboy_orders(): busca WooCommerce + externos e mescla
       - get_correios_orders(): busca WooCommerce + externos e mescla
       - get_external_orders(): busca pedidos do webhook externo (se configurado)
       - classify_order(): classifica pedido em Motoboy ou Correios
     * PPWOO_Utils expandido:
       - is_external_order(): verifica se pedido é externo
       - Funções auxiliares unificadas para WC_Order e arrays:
         * get_order_id(), get_billing_*(), get_customer_note()
         * get_order_total(), get_shipping_total(), get_coupon_codes()
         * get_shipping_methods(), get_order_items(), get_workflow_step()
     * Template atualizado:
       - Usa funções auxiliares para acessar dados (compatível com WC_Order e arrays)
       - Renderiza pedidos externos nas abas Motoboy e Correios
       - Badge WhatsApp funciona para pedidos externos

--------------------------------------------------------------------------------
CORREÇÕES REALIZADAS:
--------------------------------------------------------------------------------

1. DETECÇÃO DO WOOCOMMERCE (BUGFIX)
   - Arquivo: inc/class-packing-panel.php
   - Problema: Em alguns ambientes/ordens de carregamento, `class_exists('WooCommerce')`
              pode retornar false mesmo com WooCommerce ativo, bloqueando o painel.
   - Solução: Implementado helper `is_woocommerce_active()` com múltiplos checks:
     * function_exists('WC')
     * class_exists('WooCommerce')
